# Upstream and licensing status

Savage Soul MUD is based on [gvanderest/grim](https://github.com/gvanderest/grim).
This initial snapshot incorporates GRIM through commit `e09052d94d64cdcbc082357cd5c2c860e4a19b40` and the
Savage Soul adaptations, content conversions and supporting tools.

Upstream had no declared license when this snapshot was prepared. This file
provides attribution; it does not grant a license or claim that inherited code
has been relicensed. Licensing permission for upstream and imported content
must be clarified before distributing a licensed release. The request is tracked
in [upstream issue #158](https://github.com/gvanderest/grim/issues/158). No repository-wide
license is currently asserted. Third-party notices, including xterm.js and
its fit addon, remain beside their bundled files.

Converted world content and rules have separate provenance. Recovery notes and
conversion scripts are under migration/. Original backup archives, player data,
credentials, signing keys, build output and logs are not included.
