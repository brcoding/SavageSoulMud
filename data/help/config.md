Display settings
================

config
config <key>
config <key> <value>
config minimap off

List available settings, cycle one setting, or select a value. Use the displayed accepted values. Minimap controls the map beside room descriptions; map remains available separately.

Settings save immediately. Use screenreader on for plain text without ASCII maps,
combatlog brief|normal|detailed for combat detail, and prompt for prompt presets.
config colors off removes ANSI colors. See help screenreader, help combatlog,
and help prompt for examples.
