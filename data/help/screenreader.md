Screen reader mode

screenreader on
screenreader off

Your first login asks whether you use a screen reader. You can change this later.
On uses plain text, no ASCII maps, brief combat messages, and a spoken Ready prompt.
Off restores your previous display settings. All preferences save immediately.
Use prompt off to silence the prompt. Use look and map for room details and exits.

See also: help combatlog, help prompt, help config.
