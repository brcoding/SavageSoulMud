Wizard only: testaccount <character> on|off

Mark an existing dedicated game account for hidden testing. The named character
identifies its whole account; every character on it, including future characters,
is automatically hidden from ordinary players. No wizard powers are granted.

Use on to enable hidden testing, or off to restore normal visibility rules.
Only a wizard can change this setting. Testers cannot turn it off with wizinvis.
Other wizards can see hidden testers for supervision.

Use a separate ordinary account for testing and keep its password private.
Tests still affect the shared world. Use a development server for isolated or
destructive world-state tests.
