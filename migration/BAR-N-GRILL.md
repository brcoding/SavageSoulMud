All seven backup source files repeat the same SetLong, SetDayLong, SetNightLong and SetItems street text; upstairs is also marked outdoors. The converted text matched that source.

Distinct descriptions and inspectable fixtures are reconstructed in savsoul-reconstruction.json using the existing exit layout. Trader Sam's checkout was also a street-text placeholder without any NPC placement or matching NPC definition in the backup. Sam, his entry greeting, and the shop descriptions are reconstructed content. Buying/selling is not implemented.
